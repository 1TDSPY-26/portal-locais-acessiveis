Loading

Componente reutilizável para indicar o carregamento da página.


Uso:
    import { Loading } from "./Loading";

    <Loading />


Acessibilidade

Utiliza role="status" e aria-live="polite" para comunicar o estado de carregamento a leitores de tela.

O indicador visual possui aria-hidden="true" para não ser anunciado pelo leitor de tela.
